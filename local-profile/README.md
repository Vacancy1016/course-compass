# Course Compass · 大学航线

在项目目录运行 `python server.py`，然后访问 <http://127.0.0.1:8765/>。需要 Python 3.9+ 和支持 Web Crypto、Web Locks 的现代浏览器。首次使用点击「创建本机账号」。开发和测试可通过 `--port` 与 `--data-dir` 使用独立环境。

「建立档案 → 时间与确认」会自动保存草稿。点击确认生成独立快照；之后修改时间、课程或成果，只有再次确认才会更新首页、诊断和定向情报。建档各子页的「查看历史档案」列出每次确认的版本号、时间和内容；「时间与确认」可将草稿、全部确认记录及相关数据导出为 JSON，或删除本人档案。导出文件含个人资料，请自行保管。

学生填写的内容使用 AES-GCM 加密，留在当前浏览器的站点存储。账号服务只监听本机回环地址，使用 Python 标准库和 SQLite 保存密码校验值、会话摘要与档案密钥。会话最长 8 小时，共用设备请先退出再交给下一位学生。同一账号换浏览器不会同步档案。删除档案会清空草稿及全部历史，使旧密钥与其他登录会话失效。当前账号保持登录，可以直接重新建档。旧版只保存最近一次确认，本次升级从仍保留的记录开始编号。请保持访问地址与端口一致；清除浏览器站点数据会清除本地档案。

旧版 `course-compass-v1` 明文缓存没有账号归属，新版不会读取、迁移或删除它。共享旧设备前，由原使用者自行备份及清理旧版站点数据。GitHub Pages 或直接打开 HTML 无法运行本机身份服务。
